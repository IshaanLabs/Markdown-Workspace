# Welcome to Markdown Workspace

A cinematic, developer-first Markdown editor — split view, outline navigation, and **watermark-free PDF export** entirely in the browser.

## Why this exists

Most Markdown tools either feel utilitarian or stamp branding onto your exports. This workspace is built to feel finished: fluid motion, intentional chrome, and print-quality output you own.

### What you can try

- Edit on the left — preview updates live on the right
- Use GitHub-flavored Markdown: tables, task lists, strikethrough
- Export polished documents without leaving the page (coming next)
